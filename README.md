# 欢迎来到 IDV-Open-Events 开放平台

我们是一个由《第五人格》爱好者发起的**民间开源技术组织**。致力于为所有热爱《第五人格》的赛事主办方、OB 导播团队以及玩家社群，提供一套标准化、一站式且开箱即用的完整赛事解决方案。

---

## 为什么会有这个平台？

在第五人格丰富的民间赛事生态中，许多优秀的赛事主办方往往面临着相似的问题：
* **复杂队伍登记**：每次办比赛都要手动用表格登记，数据收集困难。
* **导播成本高**：缺乏直观的 OB 辅助工具，局内数据展示画面全靠人工包装。
* **信息传播难**：微型比赛缺乏精美的官方站点，难以累计赛事数据和选手。

## 欢迎加入我们 (Contributing)

独行快，众行远。

`idv-open-events` 是一个完全属于社区的开源组织，所有的项目源码均向全社区公开。

无论你是：
* **开发者**：擅长前端、后端、客户端或数据库设计，愿意贡献代码或修复 Bug。
* **设计师 / UI / UX**：能为赛事模板或导播软件提供更美观、更符合 IDV 风格的视觉设计。
* **赛事选手**：经验丰富的赛事策划、OB、导播或赛务，能从实际业务出发提出宝贵的功能需求（Feature Request）。

### 如何参与？
1. 浏览下方的开源仓库，寻找你感兴趣的项目。
2. 通过提交 **Issue** 提出你的想法、反馈 Bug 或讨论新功能。
3. 欢迎 Fork 我们的项目并提交 **PR**。
